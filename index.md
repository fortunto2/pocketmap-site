# PocketMap

Lightweight offline maps for iPhone, built on OpenStreetMap data.

- Download a region once and use the map with no connection.
- Search places, import GPX tracks, follow your location.
- No account, no ads. Anonymous usage counts only, never your location; off in Settings.

Map data © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright),
tiles by [OpenFreeMap](https://openfreemap.org), search by
[Nominatim](https://nominatim.org).
